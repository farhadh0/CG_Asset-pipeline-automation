# CG Asset Pipeline Automation Tool

A Python-based asset pipeline automation tool designed to simulate common
CG/VFX production pipeline workflows.

## Features

- Automated CG asset folder creation
- Asset validation
- Asset version management
- Asset publishing
- JSON-based metadata tracking
- Asset search
- Asset information display
- Pipeline report generation

## Pipeline Departments

The tool supports the following departments:

- Modeling
- Texturing
- Rigging
- Animation
- Rendering

## Technologies Used

- Python
- pathlib
- json
- shutil
- datetime
- File System Automation
